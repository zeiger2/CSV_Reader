# CSV Reader



Программа на языке C читает CSV-файл, содержащий таблицу с формулами, вычисляет значения ячеек и выводит результат в консоль в формате CSV.  

Поддерживаются арифметические операции (`+`, `-`, `\*`, `/`) и ссылки на ячейки по имени столбца и номеру строки (например, `=A1+B2`).



Требования

\- Компилятор C99: GCC, Clang или MSVC.

\- Утилита make (опционально, для автоматической сборки).

\- Стандартная библиотека C.



Автоматическая сборка с Make

1\. Убедитесь, что в системе установлены "make" и компилятор "gcc" (или "clang").

2\. Откройте терминал в корневой папке проекта.

3\. Выполните команду:

&#x20;  make (или mingw32-make)

4\. После успешной сборки в папке появится исполняемый файл csvreader.



Ручная сборка

Альтернативный вариант сборки:

1\. Убедитесь, что в системе установлен компилятор "gcc".

2\. Откройте терминал в корневой папке проекта.

3\. Выполните команду:

&#x20;  gcc -std=c99 -Wall -o csvreader main.c table.c compute.c utils.c -lm

4\. После успешной сборки в папке появится исполняемый файл csvreader.



Использование

Запустите программу, передав имя CSV-файла первым аргументом командной строки, например:

csvreader.exe tests\\all\_test.csv



Для запуска всех тестов можно использовать файл run_tests.bat или консольную команду:

for %f in (tests\\\*.csv) do csvreader.exe "%f"
